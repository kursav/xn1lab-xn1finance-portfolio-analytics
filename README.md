# XN1Finance Portfolio Analytics

`XN1Finance Portfolio Analytics` is the first planned XN1Finance SaaS application.

Its purpose is to help accounts analyze investment portfolio exposure, concentration risk, investor-profile alignment, and macro scenario sensitivity without presenting itself as a direct buy/sell recommendation engine.
